express-response-cache-middleware LIVE DEPLOYED

Live production demonstration of the express-response-cache-middleware npm package installed from the public npm registry.

Live Endpoints

  • Products Collection (Cached):
    GET /api/products X-Cache: HIT / MISS
  • Product Detail (Granular Cache):
    GET /api/products/1 tag: product:1
  • Diagnostics & Cache Stats:
    GET /api/stats
  • API Root Documentation:
    GET /api

Testing Live via curl

# 1. First fetch -> Cache MISS
curl -i https://express-response-cache-demo.vercel.app/api/products

# 2. Repeated fetch -> Cache HIT
curl -i https://express-response-cache-demo.vercel.app/api/products

# 3. Create product -> Invalidate cache
curl -i -X POST https://express-response-cache-demo.vercel.app/api/products \
  -H "Content-Type: application/json" \
  -d '{"name": "USB-C Hub", "price": 49.99}'

# 4. Fetch after mutation -> Fresh MISS
curl -i https://express-response-cache-demo.vercel.app/api/products
